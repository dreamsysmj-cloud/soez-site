사용 방법

4단계로 다이소 출고 서류 완성

1
🏢

업체 선택 · 발주 불러오기

거래처를 선택하고 다이소 발주 엑셀을 드래그&드롭하거나 파일 선택으로 불러옵니다

2
⚙️

자동 분석 · 출고 판정

헤더 자동 인식 · 제품 DB 매핑 · FEFO 선출고 판정 · 부족 시 다음 배치 자동 혼입

3
📋

발주분석 · 첨부 미리보기

카톤/파렛트 단위 변환 결과와 품질 체크리스트·생산로트 안전확인서를 화면에서 확인합니다

4
🖨️

인쇄 · 저장

엑셀·PDF로 거래처별 지정 폴더에 자동 저장하고 출고 확정 시 재고를 자동 차감

주요 기능

다이소 납품 출고 업무의 모든 반복 작업을 자동화합니다

📥

다이소 발주 엑셀 자동 분석

다이소 발주서를 자동으로 읽어들입니다. 헤더 행을 자동 인식하고 거래처마다 양식이 다르면 열 위치를 개별 매핑해 그대로 처리할 수 있습니다.

  • 발주서 헤더 행 자동 인식
  • 거래처별 발주 엑셀 열 위치 매핑 설정
  • 안성 · 남사 · 부산 센터 동적 인식
  • .xlsx 드래그&드롭 · 파일 선택 지원
🗃️

업체별 제품 DB 관리

업체별 제품 DB를 동적 센터 구성으로 관리합니다. 카톤·파렛트 입수, 유통기한/제조일자 기준 등 출고에 필요한 정보를 함께 관리합니다.

  • 업체별 제품 DB · 동적 센터 구성
  • 카톤입수 · 파렛트입수 관리
  • 유통기한 / 제조일자 기준 관리
  • 커스텀 열 추가 · 엑셀 일괄 가져오기
📦

재고 DB (입출고 원장)

품번 + 유통기한 로트 단위로 입출고를 장부에 기록합니다. 기준일 재고와 입출고 이력을 한눈에 관리합니다.

  • 품번 + 유통기한 로트 단위 관리
  • 기준일 재고 산출 · 입출고 이력 장부
  • 입고 · 출고 원장 기록
  • 출고 확정 시 재고 자동 차감
🔄

FEFO 선출고 판정

유통기한이 가까운 로트부터 먼저 출고하도록 자동 판정합니다. 재고가 부족하면 다음 배치를 자동으로 혼입해 분할합니다.

  • FEFO(선입선출) 기준 출고 가능 판정
  • 부족 시 다음 배치 자동 혼입 분할
  • 로트별 출고 수량 자동 배분
  • 출고 가능 / 부족 품목 표시
📐

카톤 · 파렛트 단위 변환

발주 수량을 카톤·파렛트 단위로 자동 변환해 출고 수량을 산출합니다. 출고 확정과 동시에 재고가 자동으로 차감됩니다.

  • 카톤 / 파렛트 단위 자동 변환
  • 입수 기준 출고 수량 산출
  • 출고 확정 시 재고 자동 차감
  • 발주분석 결과 화면 미리보기
📄

첨부파일 자동 생성

납품에 필요한 첨부 서류를 자동으로 만들어 줍니다. 생산로트별 안전확인서는 별지 다중 페이지로 자동 구성됩니다.

  • 상품 품질 체크리스트 자동 생성
  • 생산로트 상품안전확인서 (별지 다중 페이지)
  • 발주 데이터 기반 자동 채움
  • 엑셀 · PDF 동시 지원

세부 설정 옵션

거래처별로 독립 저장되는 세밀한 설정

📊 발주 · 제품 설정

  • 발주 엑셀 열 매핑 거래처별 열 위치 지정
  • 센터 구성 안성·남사·부산 동적
  • 출고 기준 유통기한 / 제조일 기준
  • 단위 변환 기준 카톤·파렛트 입수

🖥️ 인쇄 · 저장 설정

  • 인쇄 · 방향 선택 후 영구 적용
  • 거래처별 저장 폴더 거래처별 개별 지정
  • 출력 형식 엑셀 · PDF
  • 창 · 열 너비 재실행 시 자동 복원
