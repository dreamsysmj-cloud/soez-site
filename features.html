📋 거래처 통합 관리

수십, 수백 개의 거래처를 한 곳에서 관리하세요. 그룹별로 분류하고 즐겨찾기로 자주 사용하는 거래처를 빠르게 찾을 수 있습니다.

  • 거래처 이름, 주소, 연락처, 그룹 등록
  • ⭐ 즐겨찾기 기능으로 자주 쓰는 거래처 빠른 접근
  • 일반, 쿠팡, 수출 등 그룹별 분류 및 색상 구분
  • 엑셀 파일로 거래처 대량 등록 · 수정 가능
  • 거래처 검색으로 빠른 조회

  • 등록된 거래처 정보 자동 불러오기

  • 품목 프리셋으로 자주 쓰는 품목 빠른 선택

📊 엑셀 자동 저장 & 폴더 정리

생성된 송장은 택배사 양식에 맞는 엑셀 파일로 자동 저장됩니다. 연/월/일 폴더 구조로 정리되어 나중에 찾기도 쉽습니다.

  • 택배사 송장 양식에 맞는 엑셀 포맷 자동 생성
  • 파일명: 접두어_날짜_시간.xlsx 자동 생성
  • 연 → 월 → 일 하위 폴더 자동 생성
  • 생성 즉시 엑셀 자동으로 열기 옵션
  • 저장 폴더 자유롭게 변경 가능
