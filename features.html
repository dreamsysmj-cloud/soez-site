사용 방법

4단계로 택배 송장 파일 완성

1
🏢

거래처 선택

거래처를 고르면 그 거래처의 저장 설정·옵션이 자동으로 불러와지고, 하위 출고처 목록이 표시됩니다

2
🚚

출고처 · 옵션 선택

보낼 출고처를 고르고 택배사·운임·품목 등 송장 옵션을 지정합니다

3
⚡

원클릭 생성

버튼 한 번으로 택배사 양식에 맞춰 송장 파일이 자동 생성됩니다

4
💾

저장 · 이력

지정 폴더에 날짜별로 엑셀이 자동 저장되고, 생성 이력에 기록됩니다

실제 화면

택배 파일 자동화의 주요 화면을 직접 확인하세요

화면 이미지 준비 중

대시보드 — 기간·거래처별 택배 건수와 최근 생성 이력을 한눈에

주요 기능

택배 송장 업무의 반복 작업을 거래처별로 자동화합니다

🏢

거래처 · 출고처 2단계 관리

상위 '거래처' 아래에 여러 '출고처'를 두는 계층 구조로 관리합니다. 거래처마다 대표자·연락처·메모를 따로 기록할 수 있습니다.

  • 거래처(상위) — 출고처(하위) 2단계 구조
  • 거래처 관리 · 출고처 관리 화면 분리
  • 거래처별 대표자 · 연락처 · 메모
  • 엑셀로 출고처 일괄 가져오기
🔄

거래처별 설정 자동 전환

거래처를 바꾸면 파일 저장 설정과 송장 옵션이 그 거래처 기준으로 자동 전환됩니다. 어느 화면에서 바꿔도 모든 화면이 함께 따라옵니다.

  • 거래처별 파일 저장 설정 · 옵션 저장/로드
  • 전역 거래처 동기화 (전 화면 일괄 반영)
  • 마지막 선택 거래처 재시작 후 복원
  • 대시보드 · 생성 이력 거래처 필터
⚡

원클릭 송장 자동 생성

출고처와 옵션만 고르면 택배사 양식에 맞춰 송장 파일을 한 번에 만듭니다. 출고처마다 행이 자동으로 생성됩니다.

  • 버튼 한 번으로 송장 엑셀 생성
  • 출고처 건수만큼 행 자동 생성
  • 박스 수량 자동 처리
  • 생성 후 엑셀 자동 열기 옵션
📋

택배사 양식 자동 매칭

주요 택배사 양식을 내장해, 택배사를 고르면 그 양식의 열 구성에 맞춰 송장을 만듭니다. 비표준 양식은 열 위치를 직접 지정할 수 있습니다.

  • 주요 택배사 프리셋 내장
  • 헤더 이름 자동 인식 · 열 위치 매핑
  • 택배사별 헤더 샘플 엑셀 다운로드
  • 커스텀 필드 추가
💰

운임 · 품목 옵션

운임 구분·금액과 품목명을 송장 생성 시 자유롭게 지정합니다. 표기하지 않을 항목은 '미표기'로 비워둘 수 있습니다.

  • 운임 구분 (신용 · 현금 · 착불) · 금액 프리셋
  • 운임 구분 · 품목명 '미표기' 옵션
  • 운임 가격 미표기 (금액 칸 비움)
  • 출고처별 기본 운임 · 품목 지정
📊

대시보드 · 생성 이력

처리 통계와 생성 이력을 한눈에 봅니다. 거래처별로 필터링해 기간별 송장 건수와 내역을 확인할 수 있습니다.

  • 대시보드 처리 통계 · 기간 조회
  • 거래처별 필터 (전체 합산 보기 지원)
  • 생성 이력 자동 기록 · 검색
  • 좌측 메뉴 드래그로 순서 변경
