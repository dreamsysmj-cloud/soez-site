쿠팡 출고 관리

쿠팡 발주서부터 출고 분류·피킹 리스트까지, 한 번에 끝내세요.
발주 엑셀을 올리면 제품 DB 매칭과 택배·밀크런 분류가 자동으로 처리됩니다.

사용 방법

4단계로 쿠팡 출고 서류 완성

1
🏢

업체 선택 · 발주 불러오기

업체를 선택하고 쿠팡 발주 엑셀을 드래그&드롭하거나 파일 선택으로 불러옵니다

2
⚙️

자동 처리

제품 DB 매핑 · 박스수 기준 택배/밀크런 분류 · 파렛트 번호 자동 산출

3
📋

리스트 미리보기

적재(파렛트)리스트 · 피킹리스트를 화면에서 확인하고 센터별로 필터링합니다

4
🖨️

인쇄 · 저장

설정한 프린터로 바로 인쇄하고 PDF·엑셀로 지정 폴더에 자동 저장

실제 화면

쿠팡 출고 관리의 주요 화면을 직접 확인하세요

홈 — 발주 엑셀을 넣고 처리 시작, 제품 매칭·분류 자동

주요 기능

쿠팡 출고 업무의 모든 반복 작업을 자동화합니다

📥

쿠팡 발주 엑셀 자동 파싱

쿠팡 표준 발주서를 자동으로 읽어들입니다. 업체마다 양식이 다르면 열 위치를 개별 매핑해 그대로 처리할 수 있습니다.

  • 쿠팡 표준 발주 양식 자동 인식
  • 업체별 발주 엑셀 열 위치 매핑 설정
  • 헤더 행 번호 지정 (헤더 없으면 0)
  • .xlsx 드래그&드롭 · 파일 선택 지원
🗃️

업체별 제품 DB 관리

바코드와 쿠팡 SKU ID로 제품을 이중 식별합니다. 카톤·파렛트 입수, 출고가능일 등 출고에 필요한 정보를 함께 관리합니다.

  • 바코드 + SKU ID 이중 식별
  • 카톤입수 · 파렛트입수 · 묶음입수 관리
  • 유통(소비)기한 기준 출고가능일 계산
  • 커스텀 열 추가 · 엑셀 일괄 가져오기
🚚

택배 · 밀크런 자동 분류

센터별 박스 수를 합산해 배송방식을 자동으로 결정합니다. 기준 박스 수는 업체별로 조정할 수 있습니다.

  • 기준 박스 수 이하 → 택배 / 초과 → 밀크런
  • 업체별 택배 기준 박스 수 설정 (기본 9박스)
  • 출고 중지·출고불가 품목 제외 후 산출
  • 파렛트 번호(시작/끝) 자동 부여
📋

적재 · 피킹 리스트 출력

파렛트 적재리스트와 피킹리스트를 화면에서 확인하고 PDF·엑셀로 출력합니다. 센터·배송방식별 필터를 지원합니다.

  • 적재(파렛트)리스트 · 피킹리스트 생성
  • 센터 · 배송방식별 필터링
  • PDF · 엑셀 동시 지원
  • 업체별 출력 양식 템플릿 커스터마이징
🖨️

스마트 인쇄

시스템 인쇄창 없이 설정한 프린터로 바로 인쇄합니다. 세로/가로 방향은 한 번 정하면 인쇄·PDF·미리보기에 일관되게 적용됩니다.

  • 설정한 프린터로 바로 인쇄
  • 세로/가로 방향 고정 (재시작 후 유지)
  • 인쇄 미리보기 + 여백 설정
  • 인쇄 방향이 출력물과 항상 일치
💾

저장 · 출고 관리

출력물 종류별로 저장 폴더를 지정하고 파일명 접두어·날짜 폴더를 자동 적용합니다. 출고 중지 품목도 한눈에 관리합니다.

  • 발주내역 · 적재 · 피킹 저장 폴더 개별 지정
  • 파일명 접두어 + 년/월/일 하위 폴더 자동 생성
  • 출고 중지 / 출고불가 품목 표시 · 필터
  • 발주내역 다중 선택 일괄 변경 (1회성)

세부 설정 옵션

업체별로 독립 저장되는 세밀한 설정

📊 발주 · 제품 설정

  • 발주 엑셀 열 매핑 업체별 열 위치 지정
  • 택배 기준 박스 수 업체별 분류 기준
  • 출고가능일 계산 유통기한 / 제조일 기준
  • 출력 양식 템플릿 업체별 색상·열 구성

🖥️ 인쇄 · 저장 설정

  • 인쇄 프린터 · 방향 선택 후 영구 적용
  • 저장 폴더 (5종) 출력물별 개별 지정
  • 파일명 · 날짜 폴더 접두어 + 년/월/일
  • 창 · 열 너비 재실행 시 자동 복원
