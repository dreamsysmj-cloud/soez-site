모던하우스 발주서 자동화

모던하우스 발주서, 업체별 양식 그대로 자동으로 정리됩니다.
업체마다 다른 열·서식을 프로필로 저장해두면 엑셀 파일을 올리는 즉시 발주서가 완성됩니다.

사용 방법

4단계로 납품 서류 처리 완료

1
🏢

업체 선택

미리 등록된 업체 프로필에서 해당 납품처를 선택합니다

2
📂

엑셀 파일 첨부

발주서 엑셀 파일을 드래그&드롭하거나 파일 선택으로 불러옵니다

3
⚙️

처리 시작

버튼 한 번으로 센터별 열/행 숨김 처리 · 인쇄 영역 자동 설정

4
🖨️

인쇄 · 저장

처리 완료 즉시 인쇄하고 지정 폴더에 파일 자동 저장

실제 화면

모던하우스 발주서 자동화의 주요 화면을 직접 확인하세요

메인 화면 — 엑셀 발주서 드래그&드롭, 처리 후 인쇄·저장

주요 기능

물류센터 발주 업무의 모든 반복 작업을 자동화합니다

🏢

업체별 독립 프로필

여러 납품 업체를 각각 독립된 프로필로 관리합니다. 업체를 선택하는 것만으로 해당 업체의 설정이 자동으로 전환됩니다.

  • 업체 프로필 무제한 추가 · 삭제 · 이름 변경
  • 업체별 시트 설정 독립 저장
  • 업체별 파일 저장 위치 별도 지정
  • 프로필 전환 시 모든 설정 즉시 반영
📂

엑셀 파일 드래그&드롭

발주서 엑셀 파일을 프로그램 창으로 끌어다 놓기만 하면 즉시 불러옵니다. 파일 탐색기를 열 필요가 없습니다.

  • .xlsx 파일 드래그&드롭 지원
  • 파일 선택 버튼으로도 불러오기 가능
  • 파일 로드 즉시 데이터 미리보기
  • 잘못된 파일 형식 자동 차단
⚙️

납품 양식 자동 처리

센터별로 다른 납품 서류 양식에 맞게 필요 없는 열과 행을 자동으로 숨기고 인쇄 영역을 설정합니다.

  • 불필요한 열 · 행 자동 숨김 처리
  • 인쇄 영역 자동 지정
  • 데이터 시작 행 · 컬럼 인덱스 세부 설정
  • 박스 수 등 납품 수량 정보 반영
👁️

데이터 미리보기

처리 전 엑셀 데이터를 프로그램 내에서 바로 확인합니다. 잘못된 파일을 처리 전에 걸러낼 수 있습니다.

  • 파일 로드 직후 즉시 미리보기
  • 열 너비 드래그 조절 가능
  • 합계 행(합계) 하이라이트 표시
  • 처리 전 데이터 내용 확인
🖨️

원클릭 인쇄

처리 완료 직후 인쇄 버튼 한 번으로 납품 서류를 바로 출력합니다. Excel이 설치되어 있으면 추가 조작 없이 인쇄됩니다.

  • 처리 후 바로 인쇄 (처리+인쇄 통합 모드)
  • 이미 처리된 파일 별도 인쇄 모드
  • 인쇄 미리보기 지원
  • Microsoft Excel 연동 출력
💾

처리 파일 자동 저장

처리가 완료된 파일을 업체별로 지정된 폴더에 자동으로 저장합니다. 파일명은 날짜와 시간이 자동으로 포함됩니다.

  • 업체별 저장 폴더 개별 설정
  • 처리 완료 즉시 자동 저장
  • 날짜·시간 포함 파일명 자동 생성
  • 원본 파일은 bak_ 접두어로 별도 보관

세부 설정 옵션

업체별로 독립적으로 저장되는 세밀한 설정

📊 데이터 설정

  • 시트 번호 작업할 시트 위치 지정
  • 데이터 시작 행 헤더 아래 첫 데이터 행
  • 데이터 컬럼 인덱스 필드 위치 세부 지정
  • 박스 수 컬럼 납품 수량 열 위치

🖥️ 화면 · 저장 설정

  • 저장 폴더 업체별 개별 설정
  • 미리보기 열 비율 드래그로 즉시 조절
  • 창 크기 · 비율 재실행 시 자동 복원
  • 스플리터 위치 영역 크기 자동 저장
