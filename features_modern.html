사용 방법

4단계로 납품 서류 처리 완료

1
🏢

업체 선택

분류·검색으로 거래처를 찾아 선택합니다. 거래처가 100곳이 넘어도 이름 몇 글자면 충분합니다

2
📂

엑셀 파일 첨부

발주서 엑셀을 끌어다 놓거나 파일 선택으로 불러옵니다. 큰 파일도 빠르게 읽습니다

3
⚙️

처리 시작

센터별 열/행 자동 숨김 후 센터·품목·박스·쪽수 요약을 바로 보여줍니다

4
🖨️

인쇄 · PDF

거래처별 프린터로 바로 인쇄하거나 PDF로 저장합니다. 모든 페이지에 품목명 반복

실제 화면

모던하우스 발주서 자동화의 주요 화면을 직접 확인하세요

메인 화면 — 분류·검색으로 거래처 선택, 엑셀 드래그&드롭, 처리·인쇄·PDF

주요 기능

물류센터 발주 업무의 모든 반복 작업을 자동화합니다

🏢

거래처 관리

🏢 거래처 창에서 업체를 한눈에 관리합니다. 분류·담당자·연락처·주소·메모까지 함께 기록할 수 있습니다.

  • 새 거래처 · 복사해서 추가 · 삭제
  • 분류별 필터 + 이름·담당자 검색
  • 검색 결과가 하나면 Enter로 바로 선택
  • 거래처마다 설정 독립 저장
📋

설정 다른 업체에도 적용

한 거래처에서 맞춘 설정을 골라서 다른 거래처에 한 번에 적용합니다. 업체가 많아도 일일이 고칠 필요가 없습니다.

  • 적용할 항목만 골라서 체크
  • 적용할 거래처 분류·검색 후 전체 선택
  • 바뀌는 거래처 수 미리 표시
  • 공장 기본값으로 되돌리기
📂

드래그&드롭 · 빠른 불러오기

발주서 엑셀을 창으로 끌어다 놓으면 즉시 불러옵니다. 대용량 파일도 멈춤 없이 빠르게 읽습니다.

  • .xlsx 드래그&드롭 · 파일 선택
  • 대용량 파일 고속 읽기
  • 불러오는 즉시 데이터 미리보기
  • 잘못된 파일 형식 자동 차단
⚙️

납품 양식 자동 처리

센터별로 수량이 없는 열과 행을 자동으로 숨기고 인쇄 영역을 맞춥니다. 숨길 게 없거나 빈 양식이면 미리 알려줍니다.

  • 수량 0 · 빈 칸 열/행 자동 숨김
  • "0번센터" 같은 글자는 수량으로 오인하지 않음
  • 인쇄 영역 자동 지정
  • 플랜트 번호 행 서식 그대로 복사
📊

처리 결과 요약

처리가 끝나면 센터 수 · 품목 수 · 박스 합계 · 인쇄 쪽수를 바로 보여줍니다. 출력 전에 숫자로 한 번 더 확인하세요.

  • 센터 · 품목 · 박스 합계 표시
  • 합계 행은 품목 수에서 자동 제외
  • 예상 인쇄 쪽수 표시
  • 처리 로그 기록
🖨️

인쇄 · PDF 저장

처리 후 바로 인쇄하거나 PDF로 저장합니다. 거래처마다 쓰는 프린터를 지정해 둘 수 있습니다.

  • 처리 후 인쇄 / 인쇄 미리보기
  • PDF 저장
  • 거래처별 프린터 지정
  • 모든 페이지에 상품명 등 반복할 열 지정 (예: A,B)
👁️

데이터 미리보기

처리 전 엑셀 내용을 프로그램 안에서 바로 확인합니다. 보기 편하게 맞춘 배치는 그대로 기억합니다.

  • 엑셀처럼 열 너비 드래그 조절
  • 헤더를 끌어서 열 순서 변경
  • 열별 합계 표시 켜기/끄기
  • 합계 행 하이라이트
💾

처리 파일 자동 저장

처리가 끝난 파일을 거래처별로 지정한 폴더에 자동 저장합니다. 📂 파일 보기로 바로 열어볼 수 있습니다.

  • 거래처별 저장 폴더 개별 설정
  • 처리 완료 즉시 자동 저장
  • 날짜·시간 포함 파일명 자동 생성
  • 📂 파일 보기로 저장 위치 바로 열기
🧭

쉬운 설정 화면

자주 쓰는 설정만 보이는 간단 모드와 모든 설정을 다루는 고급 모드를 제공합니다. 설정 창은 크기 조절·최대화가 됩니다.

  • 간단 / 고급 모드 전환
  • 설정 창 크기 · 위치 기억
  • ❓ 사용법 버튼으로 도움말 바로 보기
  • Excel 창을 건드리지 않고 백그라운드 처리

세부 설정 옵션

거래처별로 독립 저장 · 필요하면 다른 거래처에도 한 번에 적용

📊 처리 설정

  • 시트 · 데이터 시작 행 양식 위치 지정
  • 센터 열 · 품목 열 숨김 기준 지정
  • 박스 수 · 합계 행 요약 계산 기준
  • 플랜트 번호 행 복사 원본 행 서식 그대로

🖨️ 인쇄 · 화면 설정

  • 프린터 거래처별 지정
  • 반복할 열 · 행 예: A,B — 모든 쪽에 표시
  • 저장 폴더 거래처별 개별 설정
  • 미리보기 열 너비·순서·합계 기억
